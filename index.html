Test rejimi
SMS bo'limini faollashtirish
O'chiq bo'lsa SMS hech qayerda ko'rinmaydi va yuborilmaydi. Do'konda Telegram bot ishlaydi — SMS majburiy emas.
Qanday ulanadi — 4 qadam:
1. notify.eskiz.uz saytida hisob oching (do'kon nomiga shartnoma kerak bo'ladi).
2. Kirgach: Sozlamalar → API bo'limidan Token oling.
3. Eskizdan jo'natuvchi nomini (masalan do'kon nomi) tasdiqlating.
4. Ikkalasini quyiga kiriting va Test SMS bilan tekshiring.
Hisobda pul tugasa SMS to'xtaydi — Eskiz balansini kuzatib turing.
